# tasarim

Claude için bir skill: Photoshop ve Illustrator'da profesyonel grafik tasarımcı gibi çalışma iş akışı.

- Behance logo/marka referans analizi (3-5 referans karşılaştırılır, kopyalanmaz)
- Instagram story (1080x1920) ve post (1080x1350) üretimi, katmanlı .psd + .png önizleme
- Işık, renk dengesi, vinyet, grain ve tipografik hiyerarşi kuralları
- ExtendScript (.jsx) ile Photoshop'ta otomatik kurulum ipuçları

## Kurulum

`tasarim/` klasörünü Claude skill klasörünüze kopyalayın (ör. `~/.claude/skills/tasarim/`) veya klasörü zip'leyip Claude uygulamasında skill olarak yükleyin.

## Not

Teknik akıştaki ekran koordinatları ve font adları, Windows + Photoshop 2026 (Türkçe arayüz) kurulumuna göredir; kendi ortamınızda ekran görüntüsüyle doğrulayın.
